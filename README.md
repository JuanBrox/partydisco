# Party Management · PartyDisco

Gestión de eventos de Discomóvil: agenda, clientes, presupuestos, guiones y facturación.

1. Crea un proyecto en Supabase y ejecuta `schema.sql` en el SQL Editor.
2. Sube esta carpeta a un repo de GitHub (el logo va en `assets/logo.png`).
3. En Streamlit Cloud: New app → `app.py` → pega los secrets de `.streamlit/secrets.toml.example`.
